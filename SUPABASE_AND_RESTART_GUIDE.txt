AGRIGROW - RESTART & SUPABASE DATABASE GUIDE
============================================

This file contains the complete step-by-step procedure to:
1. Start your local Django server and expose it to the internet after your PC restarts.
2. Check and verify that your user registrations and prediction data are being saved in your Supabase database.

--------------------------------------------------------------------------------

PART 1: STARTING YOUR SERVER AND TUNNEL AFTER A PC RESTART
==========================================================

When you restart your computer, your local running processes stop. Follow these steps to start them up again:

STEP 1: Run the local Django Server
-----------------------------------
1. Open Windows Command Prompt (press Win + R, type 'cmd', and press Enter).
2. Run these commands to navigate to the project directory and start the server:
   E:
   cd "E:\INTERN PROJECT\project"
   .venv\Scripts\activate
   python manage.py runserver 8000
3. KEEP THIS WINDOW OPEN. (This runs the web server locally at http://127.0.0.1:8000).

STEP 2: Start the Free Public Internet Tunnel
---------------------------------------------
1. Open a SECOND Command Prompt window (do not close the first one).
2. Run this command to expose your local port 8000 to the public internet:
   ssh -o StrictHostKeyChecking=no -R 80:localhost:8000 nokey@localhost.run
3. Look in the window for a line that looks like this:
   "https://xxxxxxx.lhr.life tunneled with tls termination"
4. Copy that URL (e.g., https://1a0e9701fc7c63.lhr.life) and paste it into your browser. The site is now live!

--------------------------------------------------------------------------------

PART 2: HOW TO CHECK IF DATA IS STORED IN SUPABASE
===================================================

Since your website is connected to Supabase via the DATABASE_URL environment variable (either locally or on Vercel), all logins, user accounts, and prediction records are saved directly in your cloud Supabase database.

To verify your data is there:

STEP 1: Log in to Supabase
--------------------------
1. Open your web browser and go to: https://supabase.com/
2. Click "Sign In" in the top right corner and enter your credentials.
3. Click on your AgriGrow project from the dashboard.

STEP 2: Open the Table Editor
-----------------------------
1. Look at the left sidebar and click on the "Table Editor" icon (it looks like a grid/table).
2. Here, you will see a list of database tables generated by Django.

STEP 3: Check your User accounts
--------------------------------
1. Select the "auth_user" table.
2. You will see a list of users registered on your site, including the default administrator ('admin') and any custom users you created.

STEP 4: Check your Prediction Records
-------------------------------------
1. Select the "recommender_predictionhistory" table.
2. This table stores all crop recommendations. You will see columns for:
   - Nitrogen (N), Phosphorus (P), Potassium (K)
   - Temperature, Humidity, pH, Rainfall
   - Predicted Crop (e.g., Rice, Coffee, Jute)
   - Status (e.g., Recommended, Cultivation, Harvested)
   - User ID (links back to the auth_user table)
   - Created At timestamp
3. Any new predictions submitted on the website will instantly appear as new rows in this table in real-time.

STEP 5: Check via SQL Query (Optional)
--------------------------------------
If you want to run custom queries to count or view predictions:
1. Click on the "SQL Editor" icon in the left sidebar (it looks like a terminal/code box).
2. Click "New Query" and type:
   SELECT * FROM recommender_predictionhistory ORDER BY created_at DESC;
3. Click "Run". This will show your latest predictions.
